## Purpose

Worksheet for classifying a new opportunity against the 4 gate definitions (No Gate / Publication Gate / Validation Gate / PhD Gate) before acting on it.

---

## Template

| Field | Entry |
|---|---|
| Opportunity / entity |  |
| Does it require only publications/LinkedIn authority? → No Gate |  |
| Does it require 1+ anchor papers but not the doctoral credential? → Publication Gate |  |
| Does it require 2+ Phase 0 validation signals but not PhD? → Validation Gate |  |
| Is the doctoral credential materially or institutionally required? → PhD Gate |  |
| Final classification + earliest realistic entry date |  |
