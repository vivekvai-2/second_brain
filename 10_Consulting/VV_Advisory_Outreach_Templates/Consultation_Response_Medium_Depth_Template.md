## Modular Blocks to Assemble

Do not draft credibility/bio/CTA prose freehand in this template — assemble from [[Modular_Blocks_Library]] to keep language consistent and centrally maintainable:

- **Block 2** — Assignment-Specific Value Proposition (pull verbatim from [[VV_Partner_Map_Master]] for the specific entity — do not templatize this one)
- **Block 3** — Evidence/Credential Module
- **Block 4** — India-Governance Positioning Module (omit if the outreach is narrowly transactional, e.g. a short empanelment form)
- **Block 5** — Call-to-Action Module (select the variant matching this template's ask type)
- **Block 6** — Conflict/Scope Disclaimer Module (include only if a defence-adjacent reading is plausible)
