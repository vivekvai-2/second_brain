## Purpose

Seven repeatable deliverable architectures, extracted from patterns already operating across the vault (the ADP engagement, the five inbound opportunity notes, the "Derivative Output Plan" sections of the four Knowledge Products, and the Batch 13/17/18 agentic-AI-security corpus cluster) rather than rebuilt from scratch each time. ## Sequencing Logic

```
Inbound_Opportunity_Intake_Template
        │  (clears conflict gate)
        ▼
Governance_Diagnostic_Report_Template  ──────► Board_AI_Risk_Oversight_Checklist ──────► Executive_Board_Briefing_Deck_Template
        │                                              ▲                                        (board-level summary reuse)
        ▼                                              │
Agentic_AI_Security_Diagnostic_Template ─────────────────┘
        │
        ▼
Workshop_Masterclass_Curriculum_Template
        │
        ▼
Advisory_Retainer_SOW_Template
```

The two diagnostics are not mutually exclusive: [[Governance_Diagnostic_Report_Template]] scores regulatory-overlap exposure across a client's full instrument stack; [[Agentic_AI_Security_Diagnostic_Template]] scores technical-governance readiness specifically for agentic/autonomous systems. A client with agentic AI deployments benefits from both — run the regulatory diagnostic first if the engagement is compliance-led, or the agentic diagnostic first if it's security/runtime-enforcement-led (e.g. an AEGIS_OS-adjacent conversation). Either diagnostic can hand off to [[Board_AI_Risk_Oversight_Checklist]] for the board-level summary, which in turn feeds the Briefing Deck's Section 4.
