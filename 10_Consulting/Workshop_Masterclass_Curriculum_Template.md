# Workshop / Masterclass Curriculum — Template

**Type:** Consulting Deliverable Template
**Status:** Active
**Created:** 2026-07-15
**Use for:** Fee-based half-day/full-day sessions — e.g. the "DPDP compliance workshop for BFSI teams" ([[DPDP_Playbook]]) and "BFSI AI Governance workshop" ([[BFSI_AI_Governance_Handbook]]) already named as derivative outputs in the vault.
**Distinguishes from:** [[Executive_Board_Briefing_Deck_Template]] — a briefing is a talk the audience receives; a workshop is an exercise the audience performs on their own institution's data.

---

## Purpose

A workshop's value is the applied exercise, not the teaching content — the teaching block exists only to make the exercise possible. This template sequences a session so participants leave with an artefact about *their own* institution, not just notes about the framework.

---

## Session Architecture

| Block | Duration (half-day / full-day) | Purpose | Output |
|---|---|---|---|
| 1. Diagnostic warm-up | 30–45 min | Participants self-score their institution using a simplified single-page version of [[Governance_Diagnostic_Report_Template]] Sections 2–4 | A rough, self-assessed Governance Debt / Coherence baseline per participant institution |
| 2. Concept teaching block | 45–60 min | Translate [[Regulatory_Parallelism]], [[Governance_Debt]], [[Institutional_Coherence]] into plain practitioner language, using the client's own sector's regulatory instruments as the worked example, not abstract cases | Shared vocabulary the room can use for the rest of the session |
| 3. Applied mapping exercise | 90 min (half-day) / 3 hrs (full-day, in two sittings) | Small groups map their own institution's overlapping mandates using the Functional Equivalence Matrix format from [[Cross_Institutional_Mandate_Comparison]] §5 | A populated Functional Equivalence Matrix per group, specific to their regulatory footprint |
| 4. Tool handoff | 30–45 min | Deliver a sector-calibrated Green/Amber/Red triage and pocket checklist (built per [[Executive_Board_Briefing_Deck_Template]] Patterns 1–2), tailored using what surfaced in Block 3 | A laminated/PDF pocket reference each participant keeps |
| 5. Action-planning close | 30–45 min | Each institution/team drafts a 30/60/90-day plan against their own Block 1 baseline and Block 3 findings | A completed 30/60/90 template per participating institution (see below) |

**Half-day total:** ~4 hours content + breaks. **Full-day total:** ~6.5 hours content + breaks, with Block 3 split across morning/afternoon and a case-study lunch discussion inserted.

## Materials Checklist

- [ ] Pre-read: 1-page sector regulatory footprint, prepared in advance from Section 1 of [[Governance_Diagnostic_Report_Template]] if a diagnostic preceded the workshop
- [ ] Blank Functional Equivalence Matrix worksheets (one per small group)
- [ ] Blank 30/60/90 templates (one per participating institution)
- [ ] Pocket reference card (Green/Amber/Red + checklist), printed or PDF
- [ ] Facilitator note: keep Block 2 anchored to the client's actual instruments — generic AI governance theory loses the room; named regulators and named clauses hold it

---

## Sequencing Notes

- **Best preceded by:** a completed [[Governance_Diagnostic_Report_Template]] engagement — Block 1 becomes much faster and more accurate if participants aren't starting cold.
- **Best followed by:** an advisory retainer conversation, using the Block 5 outputs as the scoping document.
- **Standalone viability:** the workshop works without a prior diagnostic, but budget more time in Block 1 and expect rougher self-scores.
- **Pricing anchor:** half-day and full-day as distinct fixed-fee tiers; the differentiator sold to the client is Block 3 (their own data, not a generic case study).
