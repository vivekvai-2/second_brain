## Substantive Content

### Core requirements
Requires insurers to develop **Red Flag Indicators** for fraud detection, share fraud data with the **Insurance Information Bureau (IIB)** to build a national fraud database, and establish governance structures for fraud detection and reporting.

### AI-relevance despite technology-neutral framing
Like DPDP Rule 13(3)'s algorithmic-due-diligence clause for Significant Data Fiduciaries, this framework does not name AI/ML explicitly but governs a function (fraud detection) that is increasingly AI/ML-implemented in practice — the same "technology-neutral instrument with de facto AI application" pattern already documented across the corpus (RBI cloud/outsourcing rules, DPDP SDF obligations).
