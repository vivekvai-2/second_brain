## Key Findings and Framework

### LLM Automation vs. Augmentation — the field's emerging normative line (Episodes 103, 105, 112)

Core distinction: **automation** is when an LLM replaces the scholar's cognitive work; **augmentation** is when it assists without displacing scholarly judgment. Practical heuristic offered: "ask whether the LLM is producing the idea (problematic) or helping execute a researcher-generated idea (defensible)." A sharper, more actionable version of "if it feels like a shortcut, it probably is" (Episode 95). **Directly self-referential:** this pipeline (NotebookLM extraction → Claude classification, duplicate-check, and vault-writing) sits on the augmentation side of this line by design — the researcher (Vivek) directs scope and retains judgment over classification/inclusion decisions — but the distinction is worth holding explicitly in mind as the pipeline scales, particularly regarding the next finding.

### Disclosure obligations for LLM-assisted research (Episodes 103, 105, 112)

Stated as "mandatory" in the source (a disciplinary-norm claim, not confirmed as a binding IIM Indore or journal requirement — flagged accordingly): "using LLMs to generate data or write arguments constitutes research misconduct if undisclosed"; "disclose all LLM assistance in method sections and author statements"; "use LLMs for task execution, not idea generation or data fabrication." **Direct action item:** any PRIS-derived output that flows into a P1–P4/fsQCA manuscript (literature synthesis via this corpus, any AI-assisted coding or theme generation) should be scoped for a methods-section AI-disclosure statement before submission — flagged here as a candidate addition to [[01_Strategy/VV_Publication_Pipeline_v3]]'s Drafting Discipline Protocol, not yet written into that file.

### The interpretive-act warning — most directly relevant single claim in this node (Episode 103)

"The most dangerous use of LLMs in qualitative research is having them generate thematic categories — this externalises the interpretive act." **Direct methodological caution for PRIS's own coding pipeline:** IG 2.0 rule-coding and fsQCA calibration-anchor placement are interpretive acts in exactly this sense. This node does not assert that any PRIS coding to date has crossed this line — no such claim is made or evidenced — but flags the distinction as one to hold explicitly when NVivo coding resumes for the fsQCA 10-case design (per [[08_Methods/fsQCA]]'s "Where I Am in Application" table, IG 2.0 coding is currently 0%, not yet begun).

### Prospective Sensemaking — direct corroboration of an existing P2/P3 anchor citation (episode not individually titled in the extraction; Stefan Seidel named as guest)

Seidel, Frick & vom Brocke (2025), *Regulating emerging technologies: Prospective sensemaking through abstraction and elaboration*, *MIS Quarterly* 49(1) — **this is the same paper already anchored in the vault** at [[02_Projects/Shared_Anchors/Seidel_Frick_vomBrocke_2025]], serving as the binding complementary-positioning citation for both P2 (§2, §6) and P3 (§1, §2.1). The podcast's treatment (abstraction + elaboration as regulators' two prospective-sensemaking moves) matches the existing anchor note's Core Argument exactly, with no additional technical detail beyond what the anchor already captures — **no edit made to the Shared Anchor**, per the standing practice of not editing an already-accurate note. Logged here as confirmation, not enrichment.

### Type III Errors — a citable caution for contribution framing (via Rai, 2017, referenced)

"Answering the wrong question rigorously" — a named failure mode distinct from, but complementary to, the violated-assumption contribution test (Davis 1971, resolved in F100) and the "so what" test. A useful third check for the Drafting Discipline Protocol: not just "is this interesting" but "is this even the right question."

### 2×2 Journal Decision Tool and MIS Quarterly Trifecta Framework (Thatcher; Rai, 2016)

Two further journal-evaluation frameworks (prestige-vs-rigour quadrant; impact/range/speed trifecta) extending the accumulating journal-fit toolkit from F097/F099–F101.
